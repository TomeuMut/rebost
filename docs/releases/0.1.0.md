# Rebost 0.1.0

First published baseline of the local household pantry application, before the planned Supabase phase.

## Included

- Products with categories, whole-number stock units and selectable food/container icons.
- Separate batches, preparation dates, notes and custom storage zones.
- Atomic IndexedDB stock additions, consumption and audited corrections; negative balances are rejected.
- Inventory search and filters, movement history and browser-tab refreshes.
- Spanish, English and Catalan interface, with user-entered names and notes preserved.
- Responsive layout and supplied Mallorcan fabric background.
- Static Nuxt output and Vercel build configuration.

## Validation

All nine automated tests, Nuxt type checking, server build and static generation passed on the released application source using Node.js 22.23.4. Static generation produced `.output/public/index.html`. The build emits dependency deprecation and external-resolution warnings but completes. This release does not claim a new browser review, a dependency security audit or a verified live deployment.

## Data limitations

This version stores one pantry in IndexedDB for the current browser profile and origin. It has no accounts, Supabase database, shared households, cross-device synchronization, export or backup. Clearing site data removes the pantry. Inventory dates and notes are not food-safety assessments.
